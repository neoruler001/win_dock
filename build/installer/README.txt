WinNavi Dock 설치 안내
======================

설치 (관리자 권한 불필요, 현재 사용자 전용)
  1. zip 파일을 원하는 폴더에 "모두 압축 풀기" 합니다. (압축 안에서 바로 실행하지 마세요)
  2. install.bat 을 더블클릭합니다.
  3. 질문에 답합니다.
       - 바탕화면 바로가기를 만들까요?
  4. 설치가 끝나면 독이 자동으로 실행되고, Windows 시작 프로그램에도 등록되어
     다음 부팅부터는 로그인하면 자동으로 실행됩니다.

  - 설치 위치:    %LOCALAPPDATA%\Programs\WinNavi Dock
  - 시작 메뉴에 "WinNavi Dock" 이 등록됩니다.
  - 설정 > 앱 > 설치된 앱 에서도 제거할 수 있습니다.
  - .NET 을 따로 설치할 필요가 없습니다. (실행에 필요한 런타임이 함께 들어 있습니다)
  - Windows 10 / 11 (64비트) 에서 동작합니다.

자동 실행을 끄려면
  설치 후에는 독의 설정(톱니바퀴) 또는 트레이 메뉴의 "Windows 시작 시 실행"
  체크를 해제하면 됩니다.

질문 없이 설치하려면 (배포 스크립트 등)
  install.bat -Silent                  바탕화면 바로가기: 아니오 (시작 시 실행은 항상 등록)
  install.bat -Silent -Desktop         + 바탕화면 바로가기
  install.bat -Silent -NoStartup       시작 시 자동 실행 등록 안 함
  install.bat -Silent -NoLaunch        설치 후 실행하지 않음

업데이트
  새 버전 zip 을 풀고 install.bat 을 다시 실행하면 덮어씁니다.
  아이콘 구성과 설정(%APPDATA%\WinNavi\dock.json)은 그대로 유지됩니다.

제거
  - 설정 > 앱 > 설치된 앱 > WinNavi Dock > 제거, 또는
  - 설치 폴더의 uninstall.bat 실행 (설치 폴더에 uninstall.ps1 이 복사되어 있습니다)
  - 저장된 설정까지 지우려면 제거할 때 질문에 y 로 답합니다.

설정 옮기기
  기존 PC 에서 독의 설정(톱니바퀴) > 백업... 으로 파일을 저장하고,
  새 PC 에서 설정 > 복원... 으로 불러오면 아이콘 구성과 위치를 그대로 옮길 수 있습니다.
  (아이콘은 파일 경로로 저장되므로, 새 PC 에 같은 경로의 프로그램이 있어야 표시됩니다)

문제가 있을 때
  - "Windows에서 PC를 보호했습니다" 화면이 나오면: 추가 정보 > 실행.
  - 독이 보이지 않으면: 트레이(시계 옆 ^ 안쪽)의 WinNavi Dock 아이콘 > 설정.
  - 설정 파일 위치: %APPDATA%\WinNavi\dock.json
