WinNavi Dock 포터블
===================

설치 없이 폴더째로 실행하는 버전입니다. 레지스트리·시작 메뉴·사용자 폴더(AppData)를 건드리지 않습니다.

사용법
  1. zip 을 원하는 위치(USB, 공유 폴더 등)에 "모두 압축 풀기" 합니다.
  2. WinNavi.Dock.exe 를 실행합니다.
  3. 끝낼 때는 독 또는 트레이 아이콘 우클릭 > 종료.

설정 저장 위치
  - 이 폴더의 data\dock.json (같은 폴더에 있는 portable.txt 파일이 포터블 모드 표시입니다. 지우면 일반 모드가 됩니다.)
  - 폴더를 통째로 다른 PC 로 옮기면 아이콘 구성과 설정도 함께 따라갑니다.
  - 쓰기 금지 위치(읽기 전용 USB 등)에서는 실행은 되지만 설정이 저장되지 않습니다.

알아둘 점
  - .NET 을 따로 설치할 필요가 없습니다. (런타임이 같은 폴더에 들어 있어 파일이 많습니다. 지우지 마세요.)
  - 아이콘은 파일 경로로 저장됩니다. 드라이브 문자가 바뀌는 USB 에 있는 프로그램은 경로가 달라지면 표시되지 않습니다.
  - 트레이 메뉴의 "Windows 시작 시 실행"은 지금 폴더의 exe 를 등록합니다. 폴더를 옮기면 다시 설정하세요.
  - 이미 설치 버전이 실행 중이면 포터블은 곧바로 종료됩니다. (독은 한 번에 하나만 실행됩니다)
  - 설치 버전으로 바꾸고 싶으면 설정 > 백업... 으로 저장한 뒤, 설치 버전에서 복원... 하세요.
  - "Windows에서 PC를 보호했습니다" 화면이 나오면: 추가 정보 > 실행.
